## 為什麼不能沿用現行的 HSV 門檻

藍紫光下整張影像 R≈B 高、G 低，菌斑的 HSV 色相在 H=6~54 之間亂跳、飽和度只有 47~73，
落在 `teeth_test.py` 的 `H∈[145,172]∪[0,15]` 之外。實測把現行規則原封不動跑在這兩張照片上：
標註的粉紅螢光**一個都沒抓到**，反而在嘴唇、反光燈珠上誤觸發 9 個輪廓。

## 方法：三端元光譜解混

每個像素的 BGR 視為三種光的線性疊加：

```
observed = a·V + fe·E + fp·P

V = 405nm 激發光反射（幾乎不含綠色分量）
E = 琺瑯質綠色自體螢光
P = 菌斑紅色螢光（porphyrin ~635nm）
```

三通道三未知數 → 每像素直接解 3×3 線性系統，取 `fp` 當菌斑強度。

**關鍵好處**：牙齒與紫色牙齦的交界看起來偏紅，但那份紅可以完全由 `V` 解釋，`fp` 趨近 0。
先前試過的 Lab a\* 局部對比法，最強訊號其實是這圈**邊緣偽影**而不是菌斑，完全抓錯目標。

之後再對 `fp` 做局部背景相減 + MAD 自適應門檻，消除左右照明梯度，
且門檻不綁死絕對數值 —— 換相機、拍攝距離、曝光都不必重調。

牙齒 ROI 用 **G 通道**取（琺瑯質有強綠色自體螢光、軟組織幾乎沒有），
在這種暗場照片上比 YOLO/SAM 穩，且不需要載模型。

## 已知限制

- **樣本只有 2 張**，`z_thresh` / `fp_rel_min` 有 overfit 風險。之後有更多照片時，
  優先確認 z 門檻是否還適用；端元估計（V、E）本身是每張圖自動算的，不需調。
- `P` 端元目前寫死為純紅 `(0,0,1)`。若之後拿到菌斑的實測發射光譜，換成實測值會更準。
- 目前沒有 FDI 齒位對應。要接上現有的 3D 投影流程時，需要把 G 通道 ROI 與
  `extract_plaque_regions.py` 的 SAT FDI mask 取交集 —— 那是整合階段的事。
